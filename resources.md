# Abacus Resources & Practice Tools

This page collects every resource we mention on Scholar Learn into one organized reference.

## Free Online Tools

The core practice suite we recommend is [**AbacusTool**](https://abacustool.xyz/), which offers a free online soroban, complement drills, printable worksheet generation, flash anzan for mental math training, timed speed rounds, a step-by-step solver, and a guided learning path — all without registration or payment.

For physical equipment, see our [abacus kit guide](/blog/abacus-kit).
